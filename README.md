Trabalho desenvolvido durante projeto de Iniciação Científica, com financiamento de bolsa CNPq. 

O trabalho consiste em fazer análise de dados e pré-processamento de dois datasets: a Pesquisa Nacional de Saúde (PNS) 2013 e 2019. 
Treinaremos um modelo de IA para cada dataset, treinando-o para predizer quais fatores têm maior peso na predição de diabetes em cada ano. 
Depois, os SHAP-Values de cada modelo serão analisados, a fim de termos uma ideia de como os fatores com maior importância preditiva para a diabetes mudou ao longo dos anos.
